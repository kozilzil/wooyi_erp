# Frontend

React + Vite responsive web app.

## Run

```bash
npm install
npm run dev
```

PowerShell fallback:

```powershell
npm.cmd install
npm.cmd run dev
```

## Features in bootstrap

- Login form
- Current user info (`/api/auth/me`)
- Logout
- Organization management (search/register/update/delete)
- Common code management (group query/search/register/update/delete)

## Build

```bash
npm run lint
npm run build
```
