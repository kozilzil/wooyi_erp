# 08-finance-rules

## 1. 전표 상태

- DRAFT: 작성 중
- REQUESTED: 승인 요청
- APPROVED: 승인 완료
- REJECTED: 반려
- CANCELED: 취소

## 2. 단식부기 규칙

- 수입 또는 지출 중 하나의 방향으로 기록한다.
- 최소 1개 계정과 연결되어야 한다.
- 승인 완료 전에는 장부 반영 금지
- 월마감 이후 수정 금지

## 3. 복식부기 규칙

- 차변 합계 = 대변 합계 여야 한다.
- 라인은 최소 2개 이상이어야 한다.
- 0 이하 금액 금지
- 승인 완료 전에는 장부 반영 금지
- 승인 후 수정 불가, 정정은 취소 또는 대체 전표로 처리

## 4. 승인 규칙

- 승인자는 등록자와 분리하는 것을 원칙으로 한다.
- 권한 없는 사용자는 승인 불가
- 승인 시 승인 이력 저장
- 승인 후 장부 엔트리 생성

## 5. 취소 규칙

- 승인된 전표 취소 시 취소 사유 필수
- 취소 이력 저장
- 장부 반영분 역처리 필요
- 월마감 이후 취소 정책은 관리자만 가능 또는 별도 재개방 후 처리

## 6. 마감 규칙

- 마감 전 미승인 전표 존재 여부 검사
- 마감 후 해당 기간 전표 신규/수정/삭제 제한
- 재개방은 관리자만 가능
- 마감과 재개방 모두 감사로그 필수

## 7. 보고서 반영 기준

- 승인 완료 상태만 보고서와 장부 집계에 포함
- 반려/취소 전표는 보고서 기본 집계에서 제외
