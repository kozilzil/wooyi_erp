# M02-attendance-core

## 1. 카드 정보
- 카드 ID: M02
- 제목: 출석 관리 기본 기능
- 우선순위: P1
- 모듈: 교적
- 선행 작업: M01, B02

## 2. 목표
예배별/날짜별 회원 출석을 기록하고 조회할 수 있어야 한다.

## 3. 범위
### 포함
- 출석 등록
- 출석 목록 조회
- 회원별 출석 조회
- 예배코드별 조회

### 제외
- 모바일 체크인 고도화
- QR 출석

## 4. 구현 요구사항
### 백엔드
- attendance_records 엔터티/API 구현
- 중복 출석 입력 방지 정책 구현

### 프런트엔드
- 출석 등록 화면
- 날짜/예배/회원 기준 조회 화면

### 문서
- API 계약 갱신
- ERD 보완

## 5. 처리 규칙
1. 동일 회원/동일 예배/동일 날짜 중복 입력 금지
2. 출석상태는 PRESENT, ABSENT, LATE 등 공통코드 사용

## 6. Acceptance Criteria
- [ ] 출석 등록 가능
- [ ] 날짜/예배 기준 조회 가능
- [ ] 회원별 출석 조회 가능
- [ ] 중복 입력이 차단된다

## 7. 테스트
- [ ] 출석 등록 테스트
- [ ] 중복 입력 차단 테스트
- [ ] 조회 테스트
