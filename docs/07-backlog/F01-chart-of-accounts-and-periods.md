# F01-chart-of-accounts-and-periods

## 1. 카드 정보
- 카드 ID: F01
- 제목: 회계기수 및 계정과목 관리
- 우선순위: P0
- 모듈: 재정
- 선행 작업: B01, B02

## 2. 목표
재정 모듈이 참조할 회계기수와 계정과목 체계를 관리할 수 있어야 한다.

## 3. 범위
### 포함
- 회계기수 CRUD
- 계정과목 CRUD
- 계정 트리 구조 기본 지원
- 활성/비활성 관리

### 제외
- 고급 예산 로직
- 보고서 집계

## 4. 구현 요구사항
### 백엔드
- finance_periods, finance_accounts 엔터티/API 구현
- 기수 상태 관리: OPEN, CLOSED
- 계정과목 parent-child 구조 지원

### 프런트엔드
- 회계기수 관리 화면
- 계정과목 관리 화면

### 문서
- ERD/API/재정 규칙 문서 갱신

## 5. 처리 규칙
1. 마감된 기수는 CLOSED 상태
2. 비활성 계정과목은 신규 전표 입력 시 선택 불가

## 6. Acceptance Criteria
- [ ] 회계기수 CRUD 가능
- [ ] 계정과목 CRUD 가능
- [ ] 트리 또는 계층 조회 가능
- [ ] 비활성 계정과목 정책 적용

## 7. 테스트
- [ ] 회계기수 CRUD 테스트
- [ ] 계정과목 CRUD 테스트
- [ ] 비활성 계정 조회 정책 테스트
