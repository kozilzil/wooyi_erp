# B01-auth-bootstrap

## 1. 카드 정보
- 카드 ID: B01
- 제목: 인증/권한 부트스트랩
- 우선순위: P0
- 모듈: 공통
- 선행 작업: 없음

## 2. 목표
로그인, 현재 사용자 조회, 기본 역할/권한 구조가 동작해야 한다.

## 3. 범위
### 포함
- Spring Boot 기본 보안 설정
- React 로그인 화면
- 사용자/역할/권한 기본 엔터티
- `/api/auth/login`, `/api/auth/me`, `/api/auth/logout`
- 기본 관리자 계정 시드 데이터

### 제외
- 세밀한 메뉴 권한 화면
- SSO 연동
- 2차 인증

## 4. 구현 요구사항
### 백엔드
- users, roles, permissions, user_roles, role_permissions 테이블 생성
- 로그인 API 구현
- 현재 사용자 조회 API 구현
- 비밀번호 해시 저장
- 인증 실패/권한 없음 에러 표준화

### 프런트엔드
- 로그인 화면 구현
- 로그인 성공 시 대시보드로 이동
- 로그인 실패 메시지 표시

### DB
- 기본 관리자 계정 시드
- 기본 역할 시드: SYS_ADMIN, MEMBER_ADMIN, FINANCE_ADMIN, ASSET_ADMIN

### 문서
- API 계약 갱신
- ERD 확정 반영

## 5. 처리 규칙
1. 로그인 성공 시 토큰 또는 세션 발급
2. 비활성 사용자 로그인 불가
3. `/api/auth/me`는 권한 요약을 반환해야 한다

## 6. 예외 규칙
1. 아이디/비밀번호 불일치 시 인증 실패
2. 비활성 상태 사용자 로그인 금지

## 7. Acceptance Criteria
- [ ] 로그인 성공/실패가 정상 동작한다
- [ ] 현재 사용자 조회 API가 동작한다
- [ ] 기본 관리자 계정으로 시스템 진입이 가능하다
- [ ] 권한 없는 요청은 차단된다

## 8. 테스트
- [ ] 로그인 성공 테스트
- [ ] 로그인 실패 테스트
- [ ] 비활성 사용자 차단 테스트
- [ ] `/api/auth/me` 테스트
