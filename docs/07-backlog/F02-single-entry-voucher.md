# F02-single-entry-voucher

## 1. 카드 정보
- 카드 ID: F02
- 제목: 단식부기 전표 등록/조회
- 우선순위: P0
- 모듈: 재정
- 선행 작업: F01

## 2. 목표
단식부기 방식의 수입/지출 전표를 작성하고 조회할 수 있어야 한다.

## 3. 범위
### 포함
- 단식부기 전표 등록
- 단식부기 전표 목록/상세 조회
- 수정/삭제(승인 전만)
- 승인 요청

### 제외
- 승인 처리
- 장부 반영
- 복식부기

## 4. 구현 요구사항
### 백엔드
- vouchers, voucher_lines 기본 구조 구현
- bookkeeping_mode = SINGLE 지원
- 상태: DRAFT, REQUESTED

### 프런트엔드
- 단식부기 전표 등록 폼
- 목록/상세 화면

### 문서
- API 계약 갱신
- 재정 규칙 반영

## 5. 처리 규칙
1. 금액은 양수여야 한다
2. 승인 완료 전에는 자유 수정 가능하나, 승인 요청 후 정책은 팀 규칙에 맞춘다
3. 기수 상태가 CLOSED면 저장 불가

## 6. Acceptance Criteria
- [ ] 단식부기 전표 등록 가능
- [ ] 목록/상세 조회 가능
- [ ] 승인 요청 가능
- [ ] 마감된 기수에는 저장 불가

## 7. 테스트
- [ ] 등록 테스트
- [ ] 조회 테스트
- [ ] 마감 기수 차단 테스트
- [ ] 승인 요청 상태 전환 테스트
