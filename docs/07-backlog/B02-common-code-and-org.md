# B02-common-code-and-org

## 1. 카드 정보
- 카드 ID: B02
- 제목: 공통코드 및 조직 구조 관리
- 우선순위: P0
- 모듈: 공통
- 선행 작업: B01

## 2. 목표
부서, 구역, 직분, 예배코드, 비품 상태 등 여러 모듈이 공통으로 참조할 기준 데이터를 관리할 수 있어야 한다.

## 3. 범위
### 포함
- 조직/부서 CRUD
- 공통코드 그룹/코드 CRUD
- 조회 API
- 관리 화면

### 제외
- 고급 트리 편집 UX
- 대량 업로드

## 4. 구현 요구사항
### 백엔드
- organizations, common_codes 엔터티 및 API 구현
- 그룹 코드 + 개별 코드 조회 제공
- 활성/비활성 관리

### 프런트엔드
- 조직 관리 화면
- 공통코드 관리 화면
- 검색/필터/등록/수정

### 문서
- ERD, API 계약 갱신
- 권한표 반영

## 5. 처리 규칙
1. 공통코드는 group_code 단위로 관리한다
2. 비활성 코드는 신규 입력 폼에서 선택 불가

## 6. Acceptance Criteria
- [ ] 조직 CRUD 가능
- [ ] 공통코드 CRUD 가능
- [ ] 회원/재정/비품 모듈에서 참조 가능한 조회 API 존재
- [ ] 비활성 코드가 조회 정책에 따라 처리된다

## 7. 테스트
- [ ] 조직 CRUD 테스트
- [ ] 공통코드 CRUD 테스트
- [ ] 활성/비활성 조회 테스트
