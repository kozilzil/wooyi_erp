# A01-asset-core-crud

## 1. 카드 정보
- 카드 ID: A01
- 제목: 비품 기본 CRUD
- 우선순위: P0
- 모듈: 비품
- 선행 작업: B01, B02

## 2. 목표
비품(자산)을 등록, 조회, 수정, 상태 변경할 수 있어야 한다.

## 3. 범위
### 포함
- 자산 등록
- 자산 목록/상세 조회
- 수정
- 상태 변경
- 수리 이력 기본 구조

### 제외
- 정기 조사 고도화
- 감가상각

## 4. 구현 요구사항
### 백엔드
- assets, asset_categories, asset_locations, asset_repairs 기본 구현
- 목록 필터: 부서, 장소, 상태, 분류

### 프런트엔드
- 자산 목록
- 자산 등록/수정
- 자산 상세
- 수리 이력 탭

### 문서
- ERD/API 갱신
- 권한표 갱신

## 5. 처리 규칙
1. 자산번호는 고유해야 한다
2. 상태는 공통코드 또는 enum 관리
3. 삭제는 논리 삭제 우선

## 6. Acceptance Criteria
- [ ] 자산 등록 가능
- [ ] 목록/필터 조회 가능
- [ ] 자산 수정 가능
- [ ] 수리 이력 등록 가능

## 7. 테스트
- [ ] 등록 테스트
- [ ] 중복 자산번호 차단 테스트
- [ ] 조회 필터 테스트
- [ ] 수리 이력 테스트
