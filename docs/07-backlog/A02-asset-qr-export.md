# A02-asset-qr-export

## 1. 카드 정보
- 카드 ID: A02
- 제목: 비품 QR 내보내기
- 우선순위: P1
- 모듈: 비품
- 선행 작업: A01

## 2. 목표
비품별 QR 데이터를 생성하고 외부 라벨 프로그램에서 사용할 수 있는 파일로 내보낼 수 있어야 한다.

## 3. 범위
### 포함
- QR 토큰 생성
- PNG 또는 PDF 또는 CSV 내보내기
- 단건/다건 내보내기

### 제외
- 라벨 프린터 직접 제어
- 현장 스캔 앱

## 4. 구현 요구사항
### 백엔드
- QR 데이터 생성 서비스
- 내보내기 API
- 포맷별 파일 생성

### 프런트엔드
- 단건 내보내기 버튼
- 다건 내보내기 화면 또는 액션

### 문서
- API/UI 흐름 갱신

## 5. 처리 규칙
1. QR에는 최소 자산번호, 자산명, 부서, 장소 참조가 포함
2. 다운로드 파일은 권한 사용자만 생성 가능
3. 라벨 인쇄는 시스템 외부에서 수행

## 6. Acceptance Criteria
- [ ] 단건 QR 파일 생성 가능
- [ ] 다건 QR 파일 생성 가능
- [ ] 권한 없는 사용자는 내보내기 불가
- [ ] 다운로드 가능한 포맷 1종 이상 제공

## 7. 테스트
- [ ] 단건 생성 테스트
- [ ] 다건 생성 테스트
- [ ] 권한 차단 테스트
