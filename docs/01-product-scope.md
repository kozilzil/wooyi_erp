# 01-product-scope

## 1. 프로젝트명
교회 ERP 시스템

## 2. 목적
교회 내부 행정의 핵심 영역인 교적, 재정, 비품을 하나의 웹 시스템으로 통합하여 내부 서버에서 안정적으로 운영한다.

## 3. 확정 조건
- 운영 형태: 교회 내부 서버 온프레미스
- 접근 방식: 웹 브라우저 기반
- 모바일: 전용 앱 없음, 반응형 UI만 제공
- DB: MariaDB
- 재정: 단식부기 + 복식부기 동시 지원
- QR: 외부 라벨 인쇄 프로그램 연동
- 권장 스택: Spring Boot + React + MariaDB

## 4. 1차 오픈 범위(MVP)

### 4.1 공통
- 로그인/권한관리
- 사용자/부서/조직/공통코드
- 공지사항
- 파일 업로드/다운로드
- 감사로그

### 4.2 교적관리
- 성도 기본정보 관리
- 가족/세대 관리
- 직분/부서/구역 관리
- 새신자 등록
- 출석관리
- 기본 통계
- 엑셀 업/다운로드

### 4.3 재정관리
- 회계기수 관리
- 계정과목 관리
- 단식부기 전표
- 복식부기 전표
- 전표 승인/반려/취소
- 장부 조회
- 월마감
- 기본 보고서

### 4.4 비품관리
- 자산 등록/조회/수정
- 상태 관리
- 수리 이력
- QR 출력 데이터 내보내기
- 기본 조사 기능

## 5. 2차 범위
- 심방/기도 고도화
- 교육관리 고도화
- 기부금 영수증 고도화
- 예산 승인 워크플로우 고도화
- 고급 통계/대시보드
- 문자/메일 연동

## 6. 제외 범위
- 네이티브 모바일 앱
- 내부 시스템에서 직접 라벨 프린터 드라이버 제어
- 외부 클라우드 SaaS 중심 운영
- 운영 초기 단계에서의 다국어 지원

## 7. 성공 기준
- 내부망에서 안정적으로 접속 가능
- 역할별 권한이 명확히 분리됨
- 재정 승인/취소/마감 이력이 추적 가능
- 교적/재정/비품 주요 데이터가 엑셀/PDF로 반출 가능
- 핵심 업무를 종이 없이 수행 가능
