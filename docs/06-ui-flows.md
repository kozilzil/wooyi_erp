# 06-ui-flows

## 1. 로그인
1. 로그인 화면 진입
2. 아이디/비밀번호 입력
3. 인증 성공
4. 권한 기반 대시보드 이동

## 2. 회원 등록
1. 회원 목록
2. 신규 등록 버튼
3. 기본정보 입력
4. 저장
5. 회원 상세 화면 이동
6. 감사로그 생성

## 3. 출석 등록
1. 출석 화면
2. 예배 선택
3. 날짜 선택
4. 회원 검색 또는 체크
5. 저장
6. 결과 메시지 표시

## 4. 단식부기 전표 등록
1. 전표 목록
2. 전표 등록
3. 단식부기 모드 선택
4. 수입/지출 정보 입력
5. 저장
6. 전표 상태 `DRAFT`
7. 승인 요청 가능

## 5. 복식부기 전표 등록
1. 전표 목록
2. 전표 등록
3. 복식부기 모드 선택
4. 차변/대변 라인 입력
5. 합계 검증
6. 저장
7. 승인 요청

## 6. 전표 승인
1. 승인 대기 목록
2. 전표 상세 진입
3. 승인 또는 반려
4. 승인 이력 생성
5. 승인 완료 시 장부 반영

## 7. 월마감
1. 회계기간 목록
2. 대상 기간 선택
3. 미승인 전표 존재 여부 검사
4. 마감 실행
5. 이후 수정 제한

## 8. 비품 등록
1. 비품 목록
2. 신규 등록
3. 자산 정보 입력
4. 저장
5. 상세 화면 이동

## 9. 비품 수리 등록
1. 자산 상세
2. 수리 이력 탭
3. 수리 요청 또는 수리 완료 등록
4. 상태 갱신
5. 비용 정보 저장

## 10. QR 내보내기
1. 자산 상세 또는 목록
2. QR 내보내기 선택
3. 출력 포맷 선택(PNG/PDF/CSV)
4. 파일 생성
5. 다운로드
6. 외부 라벨 프로그램에서 인쇄
